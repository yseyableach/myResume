這個專案在做什麼

排程治理入口

將排程狀態、執行紀錄與資料來源集中到單一 Console。

失敗處理流程

支援 failed restart、step restart 與 project restart，降低人工判斷成本。

相依與資料流

將 dependency tree、loop check 與 downstream impact 平台化。

執行架構轉換

逐步將可轉換批次任務導向 ADF / K8s Pod，同時保留既有 VM Job。

工程貢獻

Batch Setting / Job Console

參與 master / detail API、排程新增與編輯、DTO 檢核、狀態查詢、執行紀錄與資料來源追蹤。

Dependency & Restart

參與 dependency tree、loop check、failed restart、step restart 與指定專案重啟流程。

ADF / Pod / VM 轉換

協助批次任務遷移至 ADF / K8s Pod，並維持既有 VM 任務的管理能力。

Quality / Delivery

導入 CI/CD、SonarQube、單元測試與 Terraform。
